# 🚀 Campus Kinetic

**Campus Kinetic** is a full-stack MERN fitness and lifestyle application designed for hostel environments. It features a logic-based recommendation engine for bodyweight workouts and nutrition, dynamic calorie/BMI tracking, secure authentication, and a responsive dashboard.

## 🔗 Live Application
* **Production App:** [https://fit-hostel-ai.vercel.app](https://fit-hostel-ai.vercel.app)


## 🛠 Tech Stack
* **Frontend:** React (Vite), Tailwind CSS, React Router DOM, Lucide Icons
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas & Mongoose
* **Auth & Hosting:** JWT Authentication, Vercel (Frontend), Render (Backend)

## ✨ Key Features
* 🧠 **Smart Logic Engine:** Tailored bodyweight workout routines and hostel-friendly nutritional guidance.
* 📊 **Health Metrics:** Real-time BMI calculation and dynamic daily calorie tracking.
* 📱 **Responsive UI:** High-fidelity dashboard built with Tailwind CSS.
* 🔒 **Secure Auth:** JWT session isolation and protected API endpoints.
